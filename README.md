# דבר אליי

אתה מדבר, אני זוכר. אפליקציית PWA לניהול משימות, רעיונות וקניות בקול, בכתב ובתמונה.

- Frontend: React + Vite + vite-plugin-pwa, מתפרסם ל-GitHub Pages.
- Backend: Supabase (Postgres + RLS, Auth, Edge Functions, pg_cron).
- AI: Gemini API (מסלול חינמי) דרך Edge Function `extract`.
- התראות: Web Push דרך Edge Functions `notify` (כל דקה) ו-`push-event`.
